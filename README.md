## どんなアプリ？

**Quarta** は、残り時間を 4 色のバーで見せるタイマーです。数字を読まなくても、バーの長さと色で「あとどれくらいか」が分かります。

- 緑 → ライム → 黄 → 赤の順に色が変わり、バーは右から短くなっていきます。
- デスクトップに **ウィジェット** を置けば、アプリを開かなくても、見て、押して、使えます。
- 勉強や仕事の時間管理、料理、会議の持ち時間、休憩の目安などに使えます。

## インストールについて

Mac（macOS 14 以降）で使えます。無料です。

1. [ダウンロードページ](https://github.com/Libitech/quarta/releases/latest) を開き、`quarta-macos.dmg` をダウンロードします。
2. ダウンロードしたファイルをダブルクリックして開きます。
3. 表示された `Quarta` のアイコンを、横の `Applications`（アプリケーション）フォルダにドラッグします。
4. `アプリケーション` フォルダから `Quarta` を起動します。
5. 「通知を送信しますか？」と聞かれたら **許可** を選びます。許可しないと、終了時の音が鳴りません。

> **Note**: 本アプリは Apple による公証（Notarization）を受けています。初回起動時に「インターネットからダウンロードされたアプリケーションです」という確認が出た場合は「開く」をクリックしてください。

## 使い方

### アプリで使う

1. **時間** を決めます。分と秒を数字で指定するか、「プリセット」から選びます（3 分、5 分、25 分など）。
2. **スタート** を押します（キーボードの スペースキー でも開始できます）。
3. 終わると音と通知でお知らせします。

| 操作 | 方法 |
| --- | --- |
| 開始 / 一時停止 / 再開 | ボタン、または スペースキー |
| リセット（最初に戻す） | ボタン、または `⌘ + R` |
| 設定の表示 / 非表示 | 右上の歯車ボタン |
| 常に手前に表示 | 「最前面」にチェック |

- **くり返し**: 「回数」を 2 回以上にすると、「作業 → 休憩 → 作業 …」を自動でくり返します。休憩の長さも決められます（集中して休む、という使い方に便利です）。
- **残り半分のお知らせ**: 「残り半分になったら知らせる」をオンにすると、折り返し地点でも音が鳴ります。
- **音の選択**: 電子音、チャイム、Mac に入っている音などから選べます。「試聴」で確認できます。
- 動いている間は設定を変えられません。変えたいときは、一度リセットしてください。

### デスクトップのウィジェットで使う

アプリを開かなくても、デスクトップのウィジェットだけでタイマーを使えます。

**ウィジェットを置く**

1. デスクトップの何もないところを **右クリック** します。
2. 「ウィジェットを編集」を選びます。
3. 検索欄に「Quarta」と入力し、サイズ（小・中）を選んで追加します。

**ウィジェットでできること**

- バーと残り時間の数字が、そのまま動きます。
- ▶ ボタンで **開始 / 一時停止 / 再開**、↺ ボタンで **リセット** ができます。
- 小サイズは、残り時間・バー・ボタンだけのコンパクトな表示です。中サイズは、ボタンに文字が付き、くり返し計測のときは何回目かも表示されます。
- アプリを閉じていても動きます。
- アプリで始めたタイマーも、ウィジェットで始めたタイマーも、同じ状態です。どちらからでも止められます。
- 時間や回数、音の設定は、アプリ側で変えます。

### メニューバーから使う

- 画面上部のメニューバーに、砂時計のアイコン（動いている間はタイマーのアイコン）が出ます。
- クリックすると、残り時間の確認、開始 / 一時停止、リセットができます。
- アプリのウィンドウを閉じても、アプリは終了せず、メニューバーに残ってタイマーを続けます。
- 完全に終了するには、メニューバーのアイコンから「Quartaを終了」を選びます。
- 「ログイン時に起動」にチェックがあると、Mac を起動したときに、自動で立ち上がります。

## FAQ

- **ウィジェットの一覧に「Quarta」が出ない**
  `アプリケーション` フォルダに入れて、一度アプリを起動してください。それでも出ない場合は、Mac を再起動してみてください。
- **終了しても音が鳴らない**
  アプリを終了している間（ウィジェットだけで使っているとき）は、macOS の通知音で鳴ります。次の 3 点を確認してください。
  - 「システム設定 → 通知 → Quarta」で、通知とサウンドがオンになっているか
  - 「システム設定 → サウンド」の **「アラート音量」** が 0 になっていないか（通知音は、出力音量ではなくアラート音量で鳴ります。Quarta だけ音量を変えることはできません）
  - 「集中モード」や「おやすみモード」になっていないか（その間は鳴りません）

  アプリを起動している間は、アプリ自身が音を鳴らすので、アラート音量の影響を受けません。
- **ウィンドウが見当たらない**
  Dock のアイコンをクリックするか、メニューバーのアイコンから「タイマーを開く」を選んでください。

## アップデートと削除

- **アップデート**: 新しい `quarta-macos.dmg` をダウンロードして、同じ手順で `アプリケーション` フォルダに上書きします。
- **削除**: `アプリケーション` フォルダの `Quarta` をゴミ箱に入れます。ウィジェットも一緒に消えます。
